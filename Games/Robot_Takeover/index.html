Robot Takeover.

A text adventure I first built in Unity, rewritten in JavaScript to run in the browser. The machines run the world. Find a way to shut them down.

    // play

    keys 1–9 or click · Enter skips
    robot-takeover.sh inventory: [ ]

    $ ...

    // how_it_works

    unity → browser

    The original was a C# project in Unity. This version is plain JavaScript, so it loads instantly and runs on any phone or laptop.

    a state machine

    Each of the 45 scenes is a piece of data: its text and the choices that lead to other scenes. The engine just moves between them.

    items unlock paths

    Pick up the wrench and a locked panel opens. Some choices only appear when you carry the right item.
